# VarDepth phase v39

Опциональный CPU-этап для окончательного VCF VarDepth, Illumina BAM/CRAM,
референса, внешней фазированной панели и генетической карты.

Новый режим `coverage` добавляет точные связи HMM между соседними
информативными гетерозиготами: обе аллели представлены среди выбранных
доноров. Между ними могут находиться варианты без информации о фазе в
выбранной панели. Их эмиссии остаются в HMM, но они больше не обязаны
разрывать фазовую связь фланкирующих SNP. Исходные связи соседних вариантов
сохраняются. Зависимые вероятности не перемножаются.

Параметры выбранного режима записаны в PHASE_MODES.json. Режим `coverage`
включён по умолчанию; `--mode conservative` воспроизводит настройки v38.
Это исследовательская версия: параметры выбирались на ранее использованном
участке HG002, затем проверялись на ранее использованном участке HG005.
Такая проверка не заменяет независимую общегеномную валидацию.

Установка: Python 3, C++17-компилятор для локального выравнивания indel,
`pip install -r requirements.txt`. Первое использование может собрать
нативное ядро; для этой директории нужен доступ на запись.

```bash
python vardepth_phase39.py \
  --vcf final.vcf.gz --bam reads.bam --reference reference.fa \
  --panel unrelated-panel.bcf --genetic-map chromosome.gmap.gz \
  --sample HG002 --chrom chr22 --start 20000000 --end 24000000 \
  --workers 4 --out phase-result
```

FASTA, BAM/CRAM и панель должны иметь соответствующие индексы. Один образец
и одна хромосома за запуск. BAM RG/SM должен совпадать с именем образца VCF.
Сама панель должна быть достаточно представительной и иметь известные
исключения целевого образца/родственников; код автоматически исключает
известные семейства GIAB, но не знает родство произвольных образцов.

Выход `phased.vcf.gz`: порядок GT, символ `|`, PS, VPE и VPSRC. Выбор аллелей,
неупорядоченный GT, QUAL, FILTER, INFO и остальные FORMAT не меняются;
хеш-инвариант проверяется при завершении. Фазирование не исправляет
неверный генотип и не создаёт отсутствующие варианты.

Окна по 4 Mb независимы и не сшиваются. Между разными PS нельзя выводить
cis/trans. VPE — модельная верхняя граница суммы ошибок вдоль пути, а не
эмпирически откалиброванная вероятность ошибки. Диплоидная фаза не
определяет, какая копия материнская или отцовская. Унаследованные
PGT/PID/HP/HD/HQ требуют отдельной обработки и отклоняются.

```bash
python phase_query38.py --vcf phase-result/phased.vcf.gz --sample HG002 \
  --variant chr22:POSITION1:REF1:ALT1 --variant chr22:POSITION2:REF2:ALT2
```

Сравнение фазы использовало GIAB предварительную передачу фазы hifiasm v11,
явные PS и уверенные области; indel оценены до 50 bp. Расширение фазовых
блоков может распространять ошибочную ориентацию на большее число вариантов,
поэтому следует оценивать и переключения, и минимальную ошибку Хэмминга,
и ошибки межэкзонных ответов вместе с охватом.
