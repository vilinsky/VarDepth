# Aggregate benchmark replay

Run from this directory with Python 3.12 and NumPy 2.3.5: `python analyze.py`. No network is needed. The output is overwritten with an identical analysis except for its timestamp. `outputs/paper-check-20260929/ANALYSIS.json` stores all results; confidence intervals are conditional regional summaries of development-exposed HG005. Raw sequence, individual callsets and training matrices are not included. Comparator counts retain their original folder layout so the analysis source can remain unchanged.
